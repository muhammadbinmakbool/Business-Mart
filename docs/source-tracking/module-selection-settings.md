Here is a simple explanation of what each of the three System Modules does and what happens when you enable or disable them:

1. Source Tracking Register (sourceTracking)
This module allows you to trace your sales back to the original supplier goods intakes, showing exactly which buyer purchased which supplier's stock.

If Enabled:
The Source Tracking page is visible in the sidebar menu.
You can view and manage all purchase tracking records.
If Disabled:
The Source Tracking menu link is completely hidden from the sidebar.
Trying to visit the page directly (/source-tracking) will block you and redirect you to a "Feature Disabled" screen.
2. Supplier Mapping (supplierMapping)
This is a sub-feature of Source Tracking. It is the control that allows operators to create new links between buyers and suppliers.

If Enabled:
The New Mapping button is fully active, allowing you to establish new buyer-supplier connections.
If Disabled (Read-Only Mode):
The New Mapping button is hidden/locked.
A warning banner appears at the top of the Source Tracking page letting operators know that mapping creation is locked.
Existing links in the database remain safe and readable, but no new mappings can be created.
3. Batch Tracking (batchTracking)
This module allows you to group inventory and sales by distinct batches (for example, by date, load, or quality) instead of just managing a single bulk stock quantity.

If Enabled:
Batch selection dropdowns and inputs are visible during goods intake and invoice creation, allowing you to assign items to specific batches.
If Disabled:
All batch-level selection inputs are hidden, simplifying the interface for businesses that don't need batch-specific tracking.
